## Hard rules — DO NOT violate

1. **Lean files MUST NOT do I/O.** No `IO`, no `IO.Process.run`, no FFI. The kernel is pure.
2. **Predicate specs MUST NOT cite or read `Accounting/<Framework>/*.lean`.** Their world is the portfolio JSON + bar evidence + spec rubric.
3. **The driver MUST NOT make financial judgments.** It only routes calls and serialises results. Add fields to the JSON schema (or a new `framework` block field) rather than logic to the driver.
4. **`Facts.lean` is generated. Never hand-edit.** All `Accounting/<Framework>/Facts.lean` are gitignored. Bridge-resident transcribed facts (reconciler-attributed) are OUTSIDE this rule; the per-wave Tier-0 render is G3-checked regenerated (conformance R3/R7(5)).
5. **Defined-risk only — non-negotiable.** Any options leg outside the SIX root-chartered strategies (root CLAUDE.md § Defined-risk options) is REFUSED at the predicate layer. The kernel encodes the same restriction at the type level via the closed `Accounting.Strategy` enum. Both must remain in force. **Composition carve:** root § Defined-risk options (owner `evaluating/CLAUDE.md` § 4; worked cases also `gates.md` § R14).
6. **Bar shape canonical.** Any code that reads parquet uses the `{ts, o, h, l, c, v, adj_c}` columns; vendor names (Alpaca's `t`, etc.) never leak past `scripts/data_view.py`.
7. **Axiomatize with the top-tier model only.** Every LLM-backed extraction that produces a kept/committed result — the `extract_facts.py` driver AND the `dat-{cell,reconciler,cross,debate}` fan-out agents — runs on the latest top-tier model; haiku is forbidden for any retained artifact. Model resolves from the ONE shared seat `code/lean_tools/model_floor.py` (contract: its docstring; root § Model policy). The anti-poison guard (`_protocol_violation`) rejects + retries number-less evidence and raises if persistent; wave archives stamp `"model"`. Bake-off rationale + gate: memory `feedback_predicate_model_opus_not_haiku`.
8. **Blind-fanout confluence is the ONLY correctness oracle for the JUDGMENTAL leaf class (R4 bake-off PASS recorded 2026-08-22: class-(a) leaves in `predicates/universe/_axes/leaf-classes.json` may be Tier-0 script-extracted under spot-audits, never quorum input; gate `dat.sh --leaf-class-gate`) — and its leak channels are enumerated at their NORMATIVE HOME, never counted here** (a SEVENTH — the harness's live subagent-transcript surface, seq 338 — has an act-time arm that REFUSES, it does not CLOSE the channel: a `certified_blind` verdict attests no cell was OBSERVED to take a channel, never that one was closed) (all three axes; normative home `data/charters/studying/specs/lean4-charter-2026-06-10/axiomatize-shared-2026-07-04/SPEC.md` § 4a): (a) *filesystem write* — own `<out>/.scratch/` only; (b) *orchestrator prompt* — METHOD, never ANSWER; (c) *reads* — blindness is a READ property; (d) *memsearch recall* — BANNED; (e) *shared NAMESPACE* — bounding the CHANNEL does NOT bound the BREADTH (L-141/L-142); (f) *reconciler prior-ADJUDICATION surfaces* — canonical Lean licensed, prior tier verdicts not.
