## Hard rules — DO NOT violate

1. **Lean files MUST NOT do I/O.** No `IO`, no `IO.Process.run`, no FFI. The kernel is pure.
2. **Predicate specs MUST NOT cite or read `Accounting/<Framework>/*.lean`.** Their world is the portfolio JSON + bar evidence + spec rubric.
3. **The driver MUST NOT make financial judgments.** It only routes calls and serialises results. Add fields to the JSON schema (or a new `framework` block field) rather than logic to the driver.
4. **`Facts.lean` is generated. Never hand-edit.** All `Accounting/<Framework>/Facts.lean` are gitignored.
5. **Defined-risk only — non-negotiable.** Any options leg outside the SIX root-chartered strategies (root CLAUDE.md § Defined-risk options) is REFUSED at the predicate layer. The kernel encodes the same restriction at the type level via the closed `Accounting.Strategy` enum. Both must remain in force.
6. **Bar shape canonical.** Any code that reads parquet uses the `{ts, o, h, l, c, v, adj_c}` columns; vendor names (Alpaca's `t`, etc.) never leak past `scripts/data_view.py`.
7. **Axiomatize with the top-tier model only.** Every LLM-backed extraction that produces a kept/committed result — the `extract_facts.py` driver AND the `dat-{cell,reconciler,cross,debate}` fan-out agents — runs on the latest top-tier model; haiku is forbidden for any retained artifact. Model resolves from the ONE shared seat `code/lean_tools/model_floor.py` (`QAGENTS_AXIOMATIZE_MODEL`; legacy `QAGENTS_PREDICATE_MODEL` honored second — **plain first-hit-wins, NOT "raise-only"**, so the legacy var can LOWER the tier; G1 still refuses any sub-top-tier resolve at exit 3. Root § Model policy). The anti-poison guard (`_protocol_violation`) rejects + retries number-less evidence and raises if persistent; wave archives stamp `"model"`. Bake-off rationale + gate: memory `feedback_predicate_model_opus_not_haiku`.
8. **Blind-fanout confluence is the ONLY correctness oracle — it has SIX leak channels** (all three axes; normative home `data/charters/studying/specs/lean4-charter-2026-06-10/axiomatize-shared-2026-07-04/SPEC.md` § 4a): (a) *filesystem write* — all cell scratch under its own disjoint `<out>/.scratch/`, never the shared session scratchpad; (b) *orchestrator prompt* — name the METHOD, never the ANSWER; (c) *reads* — blindness is a READ property (root sweeps, `git status`/`diff`, sibling `pending/trading-cells/`, frozen `waves/<id>/`); (d) *memsearch recall* — BANNED for cells; (e) *shared NAMESPACE* — bounding the CHANNEL ("`#check`, don't `cat`") does NOT bound the BREADTH: a cell may `#check` only names its own brief supplies, and may never enumerate / roster / `ls` / glob-copy / `#print prefix` / env-walk by ANY mechanism (L-141/L-142); (f) *reconciler prior-ADJUDICATION surfaces* — canonical Lean is licensed, prior tier verdicts are not.
